# Dino TV · монитор компьютера

Тот же домашний экран, что и на телевизоре, только в окне на ноутбуке или мониторе ПК. Внутри — страница `/tv/` вашего сервера, поэтому отдельной настройки не нужно: экран привязывается кодом, как обычный телевизор.

## Установка

Скачайте `dino-tv-desktop-<версия>.exe` из [релизов](https://github.com/dinosaur-tv/app/releases/latest) и запустите. Установщика нет, файл portable — можно держать где угодно, в том числе на флешке.

При первом запуске укажите адрес своего сервера (`https://home.example.com`) — дальше приложение открывается сразу на экране.

- <kbd>F11</kbd> — во весь экран и обратно
- <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> — сменить адрес сервера

Окно не даёт монитору уснуть, пока экран открыт.

## Сборка

```bash
cd desktop
npm install
npm start          # запустить из исходников
npm run build      # собрать portable .exe в desktop/dist
```

Сборка на Windows требует включённого режима разработчика: electron-builder распаковывает свой тулчейн подписи, внутри которого символические ссылки, а без этой привилегии Windows их создать не даёт. В CI привилегия есть, поэтому релизные сборки собираются там — workflow `Desktop app`.

Адрес проверяется: принимается только `https` без логина, пароля, параметров и постороннего пути. Проверка живёт в `screen-url.js`, тесты — в `../test/desktop-url.test.js`.
