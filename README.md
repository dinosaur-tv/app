# Dino TV · веб-интерфейс

Экран телевизора и консоль телефона/Telegram. HTML, CSS, JavaScript.

| Адрес | Назначение |
| --- | --- |
| `/` | Главная |
| `/tv/` | Телевизор |
| `/console/` | Телефон и Telegram Mini App |

## Запуск

Разместите рядом с `backend` и используйте его fullstack Compose. Для существующего Traefik — `docker-compose.traefik.yml` в обоих репозиториях с одной сетью.

`.env.example` содержит домен и сеть. Nginx проксирует `/api/` к `dino-backend:3000`; сервер автора не используется.

При другой схеме размещения задайте публичный URL API в `config.js`. **Секреты в этот файл не добавлять.**

BotFather → Mini App/menu URL: `https://home.example.com/console/`.

## Использование

- Один сервер обслуживает несколько домов; дом выбирается селектором вверху консоли.
- Свой дом создаётся в мини-приложении, участники приходят по коду приглашения от владельца.
- Первый ТВ подтверждает владелец дома: код с экрана вводится в «Ещё».
- Телефоны подключаются по одноразовому приглашению существующего участника.
- Google Calendar: Ещё → Календари.
- Пульт появляется только при `TV_REMOTE_ENABLED=true` на backend.
- Анимации не гарантируют защиту от выгорания экрана.

## Интерьерные сцены

В пульте есть коллекции «Русская классика», «Импрессионизм» и «Авангард»:
девять репродукций с подписями. Полотно показывается целиком, часы и расписание
расположены рядом. [Каталог и источники](assets/art/README.md).

«Свет и движение» объединяет три спокойные анимации: тени окна на тёплой стене,
капли на вечернем стекле и плавающие полупрозрачные формы. Движение работает
в TV WebView, приостанавливается в фоне и учитывает уменьшение движения.

## Раскладки экрана

Сцены не верстаются по отдельности: `tv/scene-layout.js` выбирает одну из четырёх
композиций — `split` (часы слева, дела справа), `mirror` (наоборот, для картинок
с главным объектом справа), `art` (картина целиком и колонка рядом) и `night`
(крупные приглушённые часы). Тема задаёт только фон, затемнение, декор и палитру.

Фоны лежат в `assets/scenes/` (WebP, 1672 px) и `assets/scenes/4k/` (3840 px,
увеличены Real-ESRGAN). 4K-версия загружается только на экранах, которые реально
рисуют от 2560 физических пикселей, — телевизору с интерфейсом 1080p она не нужна.

Сцены «Движения» (камин, костёр, дождь, снег, сияние, звёзды, ручей, туман) — настоящее
видео: бесшовные петли 1080p H.264 без звука в `assets/scenes/motion/`, по 2–12 МБ.
Постер сцены — первый кадр петли, поэтому подмена картинки видео незаметна. Видео идёт,
только пока экран виден; во сне и под другим приложением оно на паузе
(`tv/scene-video.js`). Авторы и лицензии — `assets/ATTRIBUTIONS.md`.

Картины разложены по разделам галереи (`artCollections` в `artworks.js`). В пульте
можно повесить картину на весь экран (остаются только подпись и время) и включить
слайд-шоу по разделу или по всей галерее; настройки хранятся в `display.art`.

## Проверки

```bash
npm ci
npm run quality
npm audit
pre-commit install
pre-commit run --all-files
```

Для локальной проверки нужен HTTP-сервер и настроенный API/прокси. Тестовый `tv/_preview.json` не коммитится; режим сцены: `/tv/?scene=sea` на localhost.
